# Score / DPS Validation — clear-time grid

Clear-time (s) = targetScore(chapter, mid-level) ÷ raw DPS(Single Shot level). Real time ~1.3–1.8× higher (dodging, eggs out of fire line). Reference cannon = Single Shot (cheapest/weakest); higher-tier cannons clear faster.

targetScore = 1000 × hpMult ; hpMult = chapterMult(1→20) × levelMult(1→1.5).
